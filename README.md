# DARIKUM

DARIKUM — мини-бот для Telegram с новой механикой розыгрышей: Spin-the-Wheel (Колесо фортуны). Бот построен на Python, использует SQLite и поддерживает базовый админский контроль.

Особенности:
- Новая уникальная механика: Spin-the-Wheel
- Режимы: Spin + базовый дроп-старт
- Админ-команды для создания и завершения розыгрышей
- Точки/очки участника + статистика
- Минимальный стек: Python + python-telegram-bot + SQLite
- Готово для Docker

Ссылки:
- @BotFather для генерации токена

## Требования
- Python 3.11+
- Docker (опционально)
- Telegram Bot Token

## Настройка
1. Скопируйте .env.example в .env
2. Заполните:
   - BOT_TOKEN=...
   - ADMIN_ID=1040670594
3. Установите зависимости:
   pip install -r requirements.txt
4. Запустите:
   python main.py

## Docker
docker compose up --build

## Команды бота
- /start — приветствие
- /help — список команд
- /list — открыть список активных розыгрышей
- /join <id> — присоединиться к розыгрышу
- /my — мои очки и стрик
- /create_spin <title>|<minutes>|<label1:weight,label2:weight,...> — создать колесо
- /end_spin <id> — закрыть розыгрыш вручную
- /stats — статистика
- /admin — список админ-команд

## Пример команды создания
/create_spin Лунный шанс|30|Стикер:30,Бонус:25,Промокод:20,Ключ:15,Подарок:10

Название | минут | список весов.
Веса — это шанс. Чем больше число, тем выше вероятность.
